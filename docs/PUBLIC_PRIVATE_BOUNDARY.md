# Public / Private Architecture Boundary

This public repository is intentionally limited.

## Suitable for the public repository

- project overview and architecture summary
- Reddit data-use and privacy documentation
- setup instructions
- API schemas and examples
- non-sensitive integration scaffolding
- sample/synthetic data
- security policy

## Keep in a private repository

- full Next Wave scoring implementation and tuning
- proprietary weighting experiments and backtesting data
- production collectors and anti-noise heuristics
- private roadmap and commercial strategy
- credentials, API secrets and OAuth tokens
- live production databases
- unreleased algorithms and model-training/evaluation data
- customer or user information

The public repository exists so external API providers can understand the application's purpose and data-handling approach without exposing the full commercial implementation.
